  • ทำ ISMS ตาม ISO/IEC 27001:2022 ของบริษัทร่วมกับทีม security: สร้าง ISMS portal ใช้ภายใน (React 19, NestJS, MySQL) ครอบคลุม Clause 4–10 และ control ใน Annex A ครบ 93 ข้อ ได้แก่ risk register, Statement of Applicability, ทะเบียนสินทรัพย์, change management, ผู้ส่งมอบ, BCP และการทบทวนสิทธิ์
  • เพิ่มความปลอดภัย AWS production: ย้าย Lambda เข้า subnet แบบ private ใน VPC (NAT + VPC endpoint), จำกัดการเข้าถึงฐานข้อมูลทางเครือข่าย, ใช้ IAM สิทธิ์เท่าที่จำเป็น และย้าย credential ไปเก็บใน Secrets Manager
  • ทำ change บน production ตามขั้นตอน change management อย่างเป็นทางการ (ขออนุมัติ, ตรวจก่อนทำ, แผน rollback, เก็บ log เป็นหลักฐาน) และเขียนสคริปต์รัน change ที่หยุดทันทีเมื่อขั้นตอนใดล้มเหลว
  • ทำ backup นอกเครื่องแบบเข้ารหัสไปยัง S3 พร้อม Object Lock (แก้ไขไม่ได้) และทดสอบ restore แล้ว (RTO ประมาณ 3.5 นาที)
  • ย้าย source control ไป AWS CodeCommit พร้อมกฎการอนุมัติและให้ AI ช่วย review PR; สร้าง release gate ใน Jenkins shared library (Groovy) ที่บล็อกการ deploy production ระหว่างที่มี change hold
  • ดูแลโครงสร้างพื้นฐานของบริษัทเองบน TrueNAS (Docker, Cloudflare Tunnel) พร้อม Falco เฝ้าระวังขณะรันและ heartbeat alert; แก้ช่องโหว่ของ dependency และลบ secret ที่หลุดอยู่ใน repository
  • ออกแบบและพัฒนาระบบ ERP ระดับองค์กรด้วย React, TypeScript, GraphQL และ AWS Lambda ที่ใช้งานจริงในธุรกิจ
  • สร้างระบบ HR หลายแพลตฟอร์ม: backend NestJS, แดชบอร์ดเว็บ React และแอปมือถือ Flutter
  • พัฒนาระบบบริหารคลังสินค้า (WMS) สำหรับอุตสาหกรรมเคมีและสินค้าอันตราย ตามข้อกำหนดกรมโรงงานอุตสาหกรรม (DIW)
  • นำความสามารถ AI (Google Generative AI) และฟีเจอร์ real-time (WebSocket, OCR, สแกน QR) เข้าระบบ production
  • วาง CI/CD pipeline ด้วย Jenkins และดูแลการ deploy แบบ AWS serverless ในหลายโปรเจกต์
  • ออกแบบและจัด workshop TDD ให้ทีมพัฒนา (สองภาษา: ไทย/อังกฤษ)
  • วาง telemetry/tracing ให้ระบบ chatbot เพื่อติดตามการใช้งานและ observability
  • นำ Claude Code / Claude API มาใช้ในงานทีม: ใช้ LLM คัดแยก ticket support จาก LINE, รันแก้บั๊กอัตโนมัติบน CodeCommit และบอตแจ้งเตือนใน Discord
โปรเจกต์เด่น
ISMS Portal ตาม ISO 27001
กำลังดำเนินการ
ระบบภายในที่บริษัทใช้บริหาร ISMS ตาม ISO/IEC 27001:2022 ตั้งแต่ประเมินความเสี่ยงจนถึงหลักฐานสำหรับ audit
  • โมดูลครอบคลุม Clause 4–10 และ Annex A 2022: risk register พร้อม residual risk และการยอมรับโดยเจ้าของ, SoA (93 controls / 4 themes) พร้อม export, ทะเบียนสินทรัพย์พร้อมค่า CIA
  • Change management พร้อมวิเคราะห์ผลกระทบและประวัติการอนุมัติ; ผู้ส่งมอบ, ข้อกำหนดกฎหมาย, BCP และ log การ backup, การทบทวนสิทธิ์, competence matrix
  • ควบคุมเอกสารพร้อมประวัติเวอร์ชัน; อัปโหลดหลักฐานไป S3; แดชบอร์ดด้วย Recharts
  • รันเองบน Docker หลัง Cloudflare Tunnel; SQL migration ที่ backup ก่อนเปลี่ยนทุกครั้ง

Release Gate และระบบควบคุม Change อัตโนมัติ
กำลังดำเนินการ
กลไกที่ผูกการ deploy ผ่าน CI/CD และงาน production เข้ากับกระบวนการ change management
  • Release gate ใน Jenkins shared library: อ่านไฟล์ hold แบบเข้มงวด, ข้อมูลผิดรูปแบบถือว่าไม่ผ่าน, ไม่ยอม deploy ระหว่างที่มี hold
  • Change runner แบบ fail-fast: ทุกขั้นต้องผ่านก่อนไปขั้นถัดไป เก็บ log เป็นหลักฐาน audit
  • ขั้นตอน PR บน CodeCommit พร้อมกฎการอนุมัติ และให้ AI review ก่อนส่งคน review

ระบบแจ้งเตือน Real-time (Serverless)
เสร็จสมบูรณ์
